# Ecosim

Evolutional training of neural-network-controlled entities on a grid inspired by [this YouTube Video](https://youtu.be/N3tRFayqVtk).

## Showcase

[ecosim.webm](https://github.com/user-attachments/assets/7272f0a2-4d30-4563-aa48-c72e039b8d9f)

## Explanation

- **Red Cells:** entities controlled by one neural network each
- **Green Cells:** only entities which are located in a green cell at the end of the generation survive and contribute to the gene pool of the next generation
- **Light Gray Cells:** walls

## Usage

1. **General Settings:** use arrows to move, type the values in, select the button and press enter to continue
2. **Grid Setup:** use space to toggle modes, drag on the grid to paint areas, press enter to contiune
3. **Simulation:** type the desired TPS in and press enter to change the simulation speed, press escape to exit to settings
